## 2026-10-07. Founder gate для push

- **Решение:** без письменного «принято» от основателя агент не пушит
  в main.
- **Контекст:** утренний инцидент — read-only запрос «найди версию»
  привёл к edit + commit + push + deploy.
- **Запись:** AGENTS.md, раздел «Push and deploy — founder gate».

## 2026-10-07. .vercelignore закрывает архивы и документы

- **Решение:** *.zip, *.md, README*.txt, bin/, acceptance/, tasks/ не
  раздаются Vercel.
- **Контекст:** curl показал — платные zip, SPEC.md, AGENTS.md, а
  позже bin/build-es.mjs были публично доступны на проде.
- **Запись:** .vercelignore в корне.
- **Откат:** удалить .vercelignore, откатить деплой.

## 2026-10-07. Испанский — отдельный URL /es/ через генератор

- **Решение:** /es/index.html генерируется скриптом bin/build-es.mjs
  из index.html + ES-словарь.
- **Контекст:** Google игнорирует hreflang через ?lang=. Нужен
  отдельный URL с реальным испанским HTML.
- **Исключение:** SPEC запрещает build steps. Основатель разрешил
  скрипт-генератор как исключение. Bundler/webpack/babel по-прежнему
  запрещены.
- **Откат:** удалить /es/, bin/build-es.mjs, вернуть hreflang на
  ?lang=es.

## 2026-10-07. Стратегия — каналы, не SEO-контент

- **Решение:** продвижение через каналы (Reddit, HN, dev.to, PH).
  Не писать статьи-конкуренты для jsonviewertool.com (24 статьи, 60
  инструментов, бесплатно).
- **Контекст:** research показал, что privacy-first ниша занята
  минимум тремя игроками (jsonviewertool.com, json-indent.com,
  jsonanalyzer.com). SEO проигрышный по срокам.
- **Открытый вопрос:** формат публикаций (от первого лица vs от
  третьего).

## 2026-10-08. Meta-теги сохраняют непустой content в EN

- **Решение:** на /es/ meta title/description/og заменяются
  генератором; в index.html EN content остаётся непустым.
- **Причина:** соцсети (Slack, Facebook, X) не исполняют JS и читают
  meta из HTML-источника. Пустой content = сломанные превью.
- **Автор решения:** исполнитель (отклонился от брифа осознанно,
  объяснил).
