# GSC-01 — Выгрузка ошибок покрытия через Search Console API

**Приоритет:** High · **Статус:** ready · **Создан:** 2026-11-11
**Основание:** BACKLOG.md High («Аудит индексации в поисковиках»), SEO-PLAN.md §2

## Зачем

Ошибки покрытия GSC известны только как факт «есть»: ни один документ не
содержит их списка. Ручной экспорт из UI — 10 кликов и риск забыть. Нужен
скрипт, который делает это одной командой, чтобы видеть, что именно чинить,
и чтобы результат можно было приложить к брифу на исправление.

## Что сделать

Новый скрипт `scripts/gsc-check.mjs` (ESM, как `submit-indexnow.mjs`), который:

1. Читает креды из env (см. ниже), пишет access-токен и печатает таблицу
   ошибок.
2. Запрашивает `searchanalytics` и/или `urlInspection` API. Минимум —
   отчёт по **Coverage errors**: тип ошибки, URL, дата обнаружения.
3. Печатает человекочитаемую сводку и, опционально, `--json` для машины.

### Авторизация

Service Account через `googleapis` или прямой REST + JWT:

```
GSC_CLIENT_EMAIL=…@….iam.gserviceaccount.com
GSC_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n…"
GSC_SITE_URL=https://localjson-black.vercel.app/
```

`GSC_PRIVATE_KEY` приходит с литеральными `\n` — скрипт обязан заменять
их на реальные переводы строк (`key.replace(/\\n/g, '\n')`), иначе JWT не
подпишется. Это самая частая ошибка при первом запуске.

Репозиторий — **клиентский**, ключи только в GitHub Secrets и в локальном
`.env`, который в `.gitignore`. В выводе скрипта не должно быть самого
ключа.

### Поведение

| Ситуация | Ожидание |
| --- | --- |
| Нет env-переменных | Понятная ошибка с инструкцией, как получить креды. Не `undefined is not a function`. |
| Токен не выдался | Сообщение с HTTP-кодом от Google |
| Ошибок нет | Явное «0 ошибок» — не пустой вывод |
| Ошибки есть | Таблица: тип ошибки · URL · дата |
| `--dry-run` | Только проверка авторизации, без запроса данных |

Retry/dedup как в `scripts/submit-indexnow.mjs`: 3 попытки, backoff,
AbortController-таймаут 30 с.

## Acceptance

```bash
node --check scripts/gsc-check.mjs
node scripts/gsc-check.mjs --dry-run   # без кред — понятная ошибка
# с кредом: выводит таблицу ошибок или явные «0 ошибок»
```

Итог должен быть приложен к отчёту: сколько ошибок, какого типа, по каким
URL — чтобы можно было сразу писать бриф на исправление.

## Ограничения

- Не чинит ошибки, только выгружает.
- Не трогает `index.html`, `es/index.html`, `bin/*.mjs`.
- Не добавляет зависимостей в `package.json` без нужды: если уместен
  нативный `fetch` + JWT — предпочитать его (`submit-indexnow.mjs` уже
  работает без зависимостей).

## Если Заблокировано

Google требует, чтобы Service Account был добавлен пользователем в
проект Search Console (Settings → Users). Если нет доступа к консоли —
вернуть это основателю как блокер, не выдудывать обход.
