## Гипотеза об оффлайн-версии — разбор

**Вопрос основателя:** оффлайн-версию, возможно, выкладывали на каталог
(например AlternativeTo), где нельзя ставить прямые ссылки, но ссылки «есть в README».

**Вывод: в репозитории нет ни одного подтверждения загрузки оффлайн-версии на
каталог.** Все упоминания загрузки ведут в один адрес — Lava.top:

- `SPEC.md:270` — «Пересобираются вручную, **заливаются в Lava вручную**».
- `START-HERE.md:25-26` — «Пакеты покупателей (offline HTML + докстраница +
  README) — в zip-архивах в корне. **Заливаются в Lava вручную** после пересборки».
- `SPEC.md:271` — «`.vercelignore` блокирует `*.zip` … от публичной раздачи на
  Vercel» (коммиты bb98eee, 6feda0b). Публичной раздачи zip нет.

**Что, вероятно, и есть источник воспоминания про README:** в корне репозитория
(и поэтому в git) лежат `README.txt` / `README_es.txt`, `localjson.zip` /
`localjson-es.zip`, `LocalJSON_Pro_Offline_Version.html`. GitHub отображает
`README.txt` как README репозитория — то есть покупательская инструкция
«Thank you for your purchase!» — это ровно та «README», которую видно снаружи.
Внешних ссылок она не содержит (проверено, весь файл — 15 строк).

**Следствие:** единственный канал, где оффлайн-версия реально опубликована как
загружаемый файл, — **Lava.top**, покупателям по цене $5. Никакого свободного
каталожного листинга оффлайн-версии в репозитории не зафиксировано. Запись
AlternativeTo в SPEC не опирается ни на один коммит о загрузке — она появилась
тем же коммитом, что и запись про Product Hunt (см. ниже).

## Две проблемы документов, найденные по ходу

1. **`(confirmed by owner)` — не отметка проверки, а отметка разговора.**
   Коммит `6826dc4` (2026-08-20 21:04) добавил PH и AlternativeTo как «Active
   listing» без пометок. Коммит `6540ee9` (**через 4 минуты**, 21:08) дописал
   «(confirmed by owner)» сразу двум строкам — PH и Indie Hackers. Ни один URL
   при этом не открывался: в обоих коммитах меняется только `SPEC.md`.
   Для Indie Hackers это дало ровно тот ложный факт, который мы только что
   снимали. Для Product Hunt пометка имеет тот же вес — основатель утверждает
   листинг, я проверить не мог.
2. **`write_spec.py` — генератор спеки со старой ошибкой.** В корне репозитория
   лежит скрипт, который при повторном запуске вернёт в `SPEC.md` уже
   исправленные дефекты: строка 72 содержит `/offline/ (future)` (известный
   баг спеки), строка 94 — невыполненный TODO «Add to JSON tool directories
   (alternative.to, producthunt, etc.)». Скрипт нужно либо удалить, либо
   починить — иначе следующее поколение SPEC.md унаследует баг.

## Следующий шаг по плану

План считается живым документом: после каждой публикации строка таблицы
обновляется в том же коммите, что и сама публикация, с датой и ссылкой.
Отдельная публикация без строки в таблице считается незавершённой.
